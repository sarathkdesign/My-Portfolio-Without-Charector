# PP Neue Montreal

Licensed font files used by the site (see the `@font-face` rules at the top of `css/style.css`):

- `NeueMontreal-Regular.otf` (400) — body text, role line
- `NeueMontreal-Medium.otf` (500) — footer, menu, chip
- `NeueMontreal-Bold.otf` (700) — SARATH, caption, project labels

Light and the italics are here too but not used yet.
For faster loading, `.woff2` versions of these three files can replace the `.otf` ones.
